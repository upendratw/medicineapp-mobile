# E33 Design System

MED-1308 provides AppScreen, AppText, AppButton, AppTextInput, AppCard, AppHeader, AppAlert/InlineMessage, LoadingIndicator, and EmptyState. Semantic tokens define typography, spacing, radii, focus, error, success, warning, and information colors.

Controls have a minimum 48 px target, font scaling remains enabled, roles and labels are exposed, and disabled/loading/error states are visible. Alerts use text labels as well as color so clinical meaning never depends on color alone.
