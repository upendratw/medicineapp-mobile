# E33 Onboarding Design

MED-1310 provides welcome, self/caregiver context, accessibility entry point, and completion screens. Only non-sensitive completion/context preferences are held locally. A bounded system/enhanced accessibility preference is stored in AsyncStorage; secure tokens never use that store. No diagnosis, medical history, medication recommendation, or treatment preference is collected.

The flow states that MedicineApp supports medication management and caregiver collaboration but does not replace a doctor or pharmacist, prescribe, diagnose, or make treatment decisions. Caregiver use is explicitly described as consent-based.
