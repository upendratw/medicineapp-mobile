# E33 Reminder Alert UX

MED-1318 adds a reusable, protected reminder view with medication context, scheduled time, neutral status, large Taken/Snooze/Skip controls, and safe loading/unavailable/failure states. Production notification delivery and deep-link context remain pending E19. Development fixtures require both development mode and developer diagnostics.

The view never recommends taking, skipping, doubling, or catching up a dose. It displays instructions only when supplied by authoritative schedule context.
