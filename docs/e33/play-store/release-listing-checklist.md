# Google Play Listing Checklist

- [ ] Product/legal approve app name, short description, and full description
- [ ] Design and approve store icon and feature graphic
- [ ] Capture synthetic-data screenshots on supported devices
- [ ] Confirm Medical category and adult target-audience selections
- [ ] Provide approved support email and website
- [ ] Publish a current, public, non-geofenced HTML privacy-policy URL
- [ ] Privacy/legal approve and enter the Data Safety form
- [ ] Complete Health apps declaration and IARC content-rating questionnaire
- [ ] Provide authorized reviewer app-access/testing instructions
- [ ] Approve release notes and supported-language listings
- [ ] Verify permissions against the uploaded AAB
- [ ] Complete signing, device/version validation, and release review
- [ ] Upload and submit only after explicit release authorization
